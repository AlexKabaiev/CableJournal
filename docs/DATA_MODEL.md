# 🗄️ Специфікація моделі даних (Data Model)

## 1. Схема об'єкта запису (`CableJournalEntry`)

База даних являє собою JSON-масив об'єктів наступної структури:

```typescript
interface CableJournalEntry {
  // Системні ідентифікатори
  id: string;                      // Унікальний timestamp/UUID запису (наприклад, "1712234567890")
  
  // Розділ 1: Локація і джерело
  building: string;                // Будівля / Корпус (наприклад, "A", "B")
  floor: string;                   // Поверх (наприклад, "1", "3")
  room: string;                    // Номер кабінету / приміщення (наприклад, "305", "Серверна-1")
  connectionType: 'socket' | 'rack'; // Тип підключення (розетка або пряме в стійку)
  socketId?: string;               // ID розетки (лише для connectionType == 'socket')
  rackId?: string;                 // ID стійки джерела (лише для connectionType == 'rack')
  unit?: string;                   // Юніт джерела (наприклад, "U25")
  deviceHostname: string;          // Назва пристрою або робочої станції
  devicePort: string;              // Порт пристрою (eth0, LAN1)
  deviceType: DeviceType;          // Категорія обладнання
  
  // Розділ 2: Фізична лінія
  cableType: string;               // Тип/категорія кабелю (наприклад, "Cat6 UTP", "Cat6A S/FTP")
  cableLength?: number | string;   // Орієнтовна довжина траси у метрах
  patchCord?: string;              // Опис патч-корду (колір, довжина, категорія)
  
  // Розділ 3: Комутаційна шафа (лише для socket)
  cabinetLocation?: string;        // Розташування кросової шафи (наприклад, "A-3-SR")
  rack?: string;                   // Номер/код стійки в кросовій (наприклад, "R05")
  patchPanel?: string;             // Маркування патч-панелі (наприклад, "PP03")
  patchPanelPort?: string;         // Номер порту на патч-панелі (наприклад, "24")
  
  // Розділ 4: Активне обладнання (Комутатор)
  switchRack?: string;             // Стійка розміщення комутатора
  switchUnit?: string;             // Юніт розміщення комутатора
  switchHostname: string;          // Мережеве ім'я комутатора (наприклад, "SW-CORE-01")
  switchMgmtIp?: string;           // IP-адреса управління (наприклад, "10.0.0.1")
  switchPort: string;              // Фізичний порт світча (наприклад, "Gi1/0/12")
  speed?: string;                  // Швидкість порту (наприклад, "1000/Full")
  portType?: 'access' | 'trunk';   // Режим роботи порту
  vlanId?: string;                 // Номер VLAN (наприклад, "100")
  vlanDesc?: string;               // Опис сегмента VLAN (наприклад, "Corporate Users")
  vlanNetwork?: string;            // Підмережа (наприклад, "192.168.100.0/24")
  
  // Розділ 5: Адміністрування
  status: 'active' | 'reserve' | 'disabled' | 'test'; // Поточний статус лінії
  installDate?: string;            // Дата прокладання/підключення (YYYY-MM-DD)
  installer?: string;              // ПІБ або позивний виконавця
  lastCheck?: string;              // Дата останньої перевірки/аудиту (YYYY-MM-DD)
  notes?: string;                  // Додаткові примітки та коментарі
}
```

## 2. Допустимі словники значень

### Типи пристроїв (`DeviceType`)
| Ключ | Назва в інтерфейсі | Опис |
| :--- | :--- | :--- |
| `computer` | Комп'ютер | Робочі станції, ноутбуки, ПК співробітників |
| `server` | Сервер | Фізичні сервери, блейд-модулі |
| `printer` | Принтер | МФУ, мережеві принтери |
| `phone` | Телефон | VoIP-телефони, базові станції DECT |
| `ap` | Access Point | Бездротові точки доступу Wi-Fi |
| `camera` | Камера | IP-камери відеоспостереження |
| `other` | Інше | Інші мережеві або технологічні пристрої |

### Статуси лінії (`status`)
| Ключ | Відображення | Колір |
| :--- | :--- | :--- |
| `active` | Активний | Зелений бейдж (`bg-green-100 text-green-800`) |
| `reserve` | Резерв | Жовтий бейдж (`bg-yellow-100 text-yellow-800`) |
| `disabled` | Вимкнений | Червоний бейдж (`bg-red-100 text-red-800`) |
| `test` | Тест | Синій бейдж (`bg-blue-100 text-blue-800`) |

## 3. Формати експорту

- **CSV:** Розділювач колонок — кома або крапка з комою, кодування `UTF-8` з обов'язковим префіксом BOM (`\uFEFF`) для автоматичного розпізнавання кирилиці в Microsoft Excel без вибору кодування.
- **Excel XML (.xls):** Генерація структури `urn:schemas-microsoft-com:office:spreadsheet` з підтримкою типографіки та колонок.
- **HTML Report:** Автономна таблиця стилізована для друку та офлайн-перегляду.
