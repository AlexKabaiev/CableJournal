# 📖 Інструкція користувача CableJournal

## 1. Створення нового запису кабельного журналу

1. Натисніть кнопку **«Новий запис»** у верхньому правому куті головного вікна.
2. Заповніть необхідні секції:
   - **Локація і джерело:** Оберіть тип підключення:
     - *Через розетку:* з'являється поле для введення ID розетки (наприклад, `A-3-305-01`).
     - *Пряме підключення (rack):* з'являються поля для вказання ID стійки та номера юніта.
   - **Фізична лінія:** Вкажіть категорію кабелю (Cat5e/Cat6/Cat6A), довжину в метрах та параметри патч-корду.
   - **Комутаційна шафа:** Заповніть дані про кросову, номер патч-панелі та порт (відображається лише при підключенні через розетку).
   - **Активне обладнання:** Вкажіть комутатор, порт, швидкість, режим порту (Access/Trunk) та дані VLAN.
   - **Адміністрування:** Оберіть статус лінії (`Активний`, `Резерв`, `Вимкнений`, `Тест`), дату монтажу та ПІБ виконавця.
3. Натисніть **«Зберегти»**. Запис одразу з'явиться в загальному переліку та оновиться віджет статистики.

---

## 2. Швидкий пошук та фільтрація

- **Пошуковий рядок:** Здійснює динамічний регістронезалежний пошук за всіма текстовими полями одночасно (за ім'ям ПК, IP-адресою, номером кімнати, назвою комутатора чи VLAN).
- **Фільтр за типом:** Дозволяє виділити лише лінії через розетку або лише міжстійкові підключення.
- **Фільтр за статусом:** Дозволяє відфільтрувати активні чи резервні лінії.

---

## 3. Редагування, дублювання та видалення

На картці кожного запису доступні дії:
- ✏️ **Редагувати:** відкриває модальну форму із заповненими даними.
- 📋 **Дублювати:** створює копію поточного запису (зручно при масовому підключенні кабінету або цілого ряду розеток).
- 🗑️ **Видалити:** запитує підтвердження та видаляє запис із локальної бази даних.

---

## 4. Експорт даних та формування звітів

Натисніть кнопку **«Excel»** у верхньому меню для відкриття вікна вибору формату:
- **CSV (Excel):** Експортує таблицю у формат CSV з кодуванням `UTF-8 + BOM`. Файл відкривається в MS Excel або Google Sheets без спотворення українських літер.
- **Excel XML (.xls):** Формує XML-документ книги Excel із фіксованими заголовками.
- **HTML:** Зберігає самодостатній файл із таблицею, яку можна переглядати в будь-якому браузері без додаткових програм.
- **Експорт (JSON):** Зберігає повну структуру бази даних для перенесення на інший комп'ютер.

---

## 5. Друк кабельного журналу

Натисніть кнопку **«Друк»**:
- Автоматично відкривається вікно попереднього перегляду друку.
- Таблиця оптимізована для альбомної орієнтації (`A4 Landscape`), використовує компактні розміри шрифтів та кольорову індикацію статусів.

---

## 6. Резервне копіювання (Backup)

- Кнопка **«Backup»** створює миттєву копію поточної бази даних у вкладеному каталозі `backups/` поруч із програмою (ім'я файлу формується з поточної дати та часу: `backup_YYYY-MM-DDTHH-mm-ss.json`).
- Для відновлення з резервної копії скористайтесь кнопкою **«Імпорт»** та оберіть потрібний `.json` файл із папки `backups/`.
